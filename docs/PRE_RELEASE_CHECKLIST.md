# Pre-release checklist

Этот чеклист используется перед экспериментальной публикацией или передачей приложения на ручную проверку. Он не означает, что деплой уже настроен или выполнен.

## Git status clean

- [ ] Выполнить `git status --short`.
  Ожидаемый результат: нет незакоммиченных изменений.

- [ ] Проверить последние коммиты через `git log --oneline -5`.
  Ожидаемый результат: в истории видны ожидаемые изменения.

## npm checks

- [ ] Выполнить `npm run lint`.
  Ожидаемый результат: команда завершается без ошибок.

- [ ] Выполнить `npm run typecheck`.
  Ожидаемый результат: TypeScript-проверка завершается без ошибок.

- [ ] Выполнить `npm run test:run`.
  Ожидаемый результат: все unit tests проходят.

- [ ] Выполнить `npm run build`.
  Ожидаемый результат: production build завершается без ошибок.

## Manual QA completed

- [ ] Пройти основной план из `docs/MANUAL_TEST_PLAN.md`.
  Ожидаемый результат: критичные сценарии отмечены как `PASS` или имеют оформленные дефекты.

- [ ] Заполнить результаты по шаблону `docs/MANUAL_TEST_RESULTS_TEMPLATE.md`.
  Ожидаемый результат: есть итоговый статус проверки и список найденных дефектов.

- [ ] При необходимости использовать fixtures из `docs/QA_FIXTURES.md`.
  Ожидаемый результат: валидные JSON импортируются, невалидные корректно отклоняются.

## Mobile iOS checked

- [ ] Проверить приложение в iOS Safari.
  Ожидаемый результат: приложение открывается, Spin mode работает, жесты не ломают страницу.

- [ ] Проверить загрузку/перезагрузку после локального сохранения.
  Ожидаемый результат: текущий барабан и история восстанавливаются ожидаемо.

## Mobile Android checked

- [ ] Проверить приложение в Android Chrome.
  Ожидаемый результат: приложение открывается, Spin mode работает, жесты не вызывают случайный scroll внутри барабана.

- [ ] Проверить Edit mode на реальном Android-устройстве.
  Ожидаемый результат: поля, кнопки, sliders и file inputs доступны для касания.

## JSON import/export checked

- [ ] Экспортировать текущий конфиг.
  Ожидаемый результат: скачивается `vertical-wheel-config.json`.

- [ ] Проверить, что экспорт содержит полный `WheelConfig`, включая изображения.
  Ожидаемый результат: data images и image URL присутствуют в JSON export.

- [ ] Импортировать валидный JSON.
  Ожидаемый результат: текущий барабан заменяется импортированным и сохраняется локально.

- [ ] Импортировать невалидный JSON.
  Ожидаемый результат: показывается русская ошибка, текущий барабан не ломается.

## Share links checked

- [ ] Скопировать share link из Edit mode.
  Ожидаемый результат: ссылка копируется или показывается понятная ошибка clipboard.

- [ ] Открыть share link в том же браузере.
  Ожидаемый результат: барабан из ссылки загружается и открывается Spin mode.

- [ ] Открыть share link в другом браузере или устройстве.
  Ожидаемый результат: барабан загружается без локальной истории.

- [ ] Проверить, что картинки не попадают в share link.
  Ожидаемый результат: ни data images, ни image URL не восстанавливаются из ссылки.

## Unicode checked

- [ ] Проверить кириллицу в title/subtitle барабана и опций.
  Ожидаемый результат: текст сохраняется, отображается, экспортируется и проходит через share link.

- [ ] Проверить emoji в title/subtitle и отдельном emoji-поле.
  Ожидаемый результат: emoji не ломаются в UI, JSON export/import и share link.

- [ ] Проверить смешанный English/Russian/emoji текст.
  Ожидаемый результат: текст проходит roundtrip без повреждений.

## No console errors

- [ ] Открыть browser console на первом запуске.
  Ожидаемый результат: нет ошибок JavaScript, React, IndexedDB или Vite.

- [ ] Проверить console после spin, edit, import/export, share и image upload.
  Ожидаемый результат: нет неожиданных ошибок; в `?debug=1` допустимы только ожидаемые `console.debug` события.

## Build completed

- [ ] Выполнить `npm run build`.
  Ожидаемый результат: папка `dist/` создается/обновляется, сборка завершается успешно.

- [ ] При необходимости локально проверить production build через Vite preview.
  Ожидаемый результат: собранное приложение открывается и выполняет базовые сценарии.

## Hosting/deployment notes

- [ ] Подтвердить выбранный hosting для static SPA.
  Ожидаемый результат: понятно, куда будет загружаться содержимое `dist/`.

- [ ] Проверить, что hosting отдает `index.html` и статические assets.
  Ожидаемый результат: прямое открытие базового URL работает.

- [ ] Проверить поведение URL с hash `#wheel=...`.
  Ожидаемый результат: hosting не удаляет hash, приложение может прочитать share config.

- [ ] Не заявлять backend/API как часть релиза.
  Ожидаемый результат: релиз описан как client-only static app.

## Known limitations

- [ ] Share link не содержит изображения.
- [ ] История не входит в share link.
- [ ] Image URL хранится как URL и не скачивается приложением.
- [ ] Clipboard API может быть недоступен в некоторых браузерах или небезопасных контекстах.
- [ ] Сжатие изображений зависит от Canvas API и поддержки WebP/JPEG в браузере.
- [ ] Debug mode включается только вручную через `?debug=1`.

## Rollback notes

- [ ] Зафиксировать commit hash текущего релизного кандидата.
  Ожидаемый результат: понятно, к какому коммиту нужно вернуться.

- [ ] Зафиксировать предыдущий стабильный commit hash.
  Ожидаемый результат: есть понятная rollback-точка.

- [ ] Если используется static hosting, сохранить способ отката.
  Ожидаемый результат: известно, как вернуть предыдущую версию `dist/` или предыдущий deployment.

- [ ] Проверить, что rollback не требует миграций backend.
  Ожидаемый результат: backend отсутствует, rollback касается только client bundle.
