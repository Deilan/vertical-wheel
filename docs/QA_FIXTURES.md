# QA fixtures для ручного импорта

Папка `test-fixtures/` содержит JSON-конфиги для проверки импорта в редакторе. Все валидные файлы используют `WheelConfig` version `1`. Файлы с префиксом `invalid-` специально невалидны: приложение должно показать русскую ошибку и не сломать текущий барабан.

## Как использовать

1. Запустите приложение.
2. Откройте режим «Редактор».
3. Нажмите «Импорт JSON».
4. Выберите один из файлов из `test-fixtures/`.
5. Сравните результат с ожидаемым поведением ниже.

## Валидные fixtures

| Файл | Для чего нужен | Ожидаемый результат |
| --- | --- | --- |
| `simple-russian-emoji.json` | Базовый импорт с кириллицей и emoji. | Импорт проходит, открывается Spin mode, заголовки и emoji отображаются корректно. |
| `long-text.json` | Длинные title/subtitle в пределах лимитов. | Импорт проходит, длинный текст не ломает карточки и обрезается визуально аккуратно. |
| `max-30-options.json` | Проверка максимального допустимого числа опций. | Импорт проходит, у барабана ровно 30 опций, редактор не предлагает добавить 31-ю. |
| `colors-and-sizes.json` | Визуальные настройки на краях разрешенных диапазонов. | Импорт проходит, цвета и размеры применяются к Spin mode и preview. |
| `image-url.json` | Проверка image URL без base64 и без скачивания в конфиг. | Импорт проходит, картинка берется из URL; JSON остается с `kind: "url"`. |
| `option-exclusion-rules.json` | Проверка правил исключения после результата: global ask, per-option overrides, hidden/visible-disabled decisions. | Импорт проходит, открывается Spin mode, текущих исключенных опций нет; после spin применяются правила поведения. |

## Невалидные fixtures

| Файл | Почему невалиден | Ожидаемый результат |
| --- | --- | --- |
| `invalid-too-few-options.json` | В конфиге только одна опция при минимуме 2. | Импорт отклоняется, показывается русская ошибка, текущий барабан остается рабочим. |
| `invalid-duplicate-ids.json` | Две опции имеют одинаковый `id`. | Импорт отклоняется, показывается русская ошибка про повторяющиеся id. |

## Примечания

- Fixtures не содержат base64 image blobs.
- Fixtures с правилами исключения содержат только правила поведения в `WheelConfig`, но не текущее session state исключенных опций.
- Для проверки локальной загрузки картинок используйте реальные PNG/JPG/JPEG/WebP файлы вручную.
- Share link должен сохранять URL картинки после импорта `image-url.json`, но по-прежнему исключать локальные data/base64 картинки.
